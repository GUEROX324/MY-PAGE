MI PÁGINA PERSONAL — GUÍA PARA VS CODE

1. Descomprime el ZIP. Abre VS Code y ve a Archivo > Abrir carpeta. Selecciona mi-pagina-personal.
2. Abre index.html. Contiene los textos, las secciones y los enlaces del menú.
3. Abre styles.css. Contiene los colores, tamaños y diseño para celular y computadora.
4. Para ver la página sin publicar, abre index.html con tu navegador. Guarda cambios en VS Code y actualiza la pestaña del navegador.
5. Edita primero nombre, descripción, formación, proyectos y conocimientos. Revisa que todo lo que vayas a publicar pueda ser visible para cualquier persona.
6. Si quieres poner documentos, crea una carpeta llamada documentos junto a index.html. Copia allí únicamente los PDF que desees hacer públicos. Después añade los enlaces correspondientes dentro de la sección Documentos de index.html. Ejemplo:
   <a href="documentos/mi-trabajo.pdf" target="_blank" rel="noopener">Ver mi trabajo</a>
   Evita espacios y acentos en los nombres de archivo para que los enlaces sean fáciles de mantener.
7. Cuando esté lista: en Netlify puedes arrastrar la carpeta mi-pagina-personal o este ZIP a Netlify Drop. En Hostinger con hosting web tradicional, sube los archivos dentro de public_html; index.html debe quedar en la raíz de public_html. No publiques hasta revisar los datos y documentos.

ESTRUCTURA
mi-pagina-personal/
  index.html       contenido
  styles.css       apariencia
  LEEME.txt        esta guía (puedes excluirla al publicar)
  documentos/      crear cuando elijas archivos

Esta versión es HTML y CSS. No requiere Angular, Node.js ni instalar dependencias.
